 # Lina's Farm — Gizlilik Politikası / Privacy Policy

  kidolab'ın **Lina'nın Çiftliği (Lina's Farm)** adlı Android oyununun gizlilik politikası.
  Sayfa GitHub Pages ile yayınlanır:

  **https://kidolab-studio.github.io/linasfarm-privacy-policy/**

  Bu adres Google Play Console'da uygulamanın "Gizlilik politikası" alanına girilir.
  Aynı metin oyunun içinde, Ebeveyn Köşesi'nde de bulunur.

  ## Dosyalar

  - `index.html` — gizlilik politikası; Türkçe ve İngilizce aynı sayfada.

  ## Güncelleme

  1. `index.html`'yi düzenle; Türkçe ve İngilizce bölümleri birlikte güncelle.
  2. İki bölümdeki "Yürürlük tarihi" / "Effective date" satırını değişikliğin tarihiyle değiştir.
  3. Oyunun içindeki metni de aynı şekilde güncelle (Ebeveyn Köşesi).
  4. `main` dalına gönder; GitHub Pages birkaç dakika içinde yeni hali yayınlar.

  Sayfa dış kaynak (yazı tipi, betik, analiz aracı) kullanmayan tek dosyalık düz HTML'dir.
  Politikadaki "veri toplamıyoruz" sözüyle çelişmemesi için sayfaya izleme kodu ya da
  dış kaynak eklenmemelidir.
